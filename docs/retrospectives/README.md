# retrospectives/ 目录（复盘）

> 由 R99-PM 维护。存放阶段性/定量复盘文档，解决「度量采集了但永远不被使用」的问题。

## 触发时机

| 时机 | 说明 |
|------|------|
| 每完成 10 张任务卡 | 默认节奏，校准估算 + 流程体检 |
| 每个阶段结束 | 产品设计 → UIUX → 原型 → 架构 → 开发 → 验收 |
| 重大返工 / 事故后 | 大面积驳回、P0 Bug 集群、多卡返工 |

## 输入（PM 汇总）

- `reports/` 各回报 §9 度量信息（实际轮数 / 实际耗时 / 返工次数 / 主要耗时环节）
- Bug 统计（P0-P3 分布，来源 `reports/` §5）
- 契约偏离记录（`reports/` §6 + `docs/decisions.md`）
- 阶段内关键决策（`docs/decisions.md`）

## 输出（每篇必含）

1. **估算校准表**：预计轮数 vs 实际轮数偏差率；下一批任务的估算修正建议
2. **至少 1 条可执行流程改进**：直接更新 docs / 角色文件，或记入 decisions.md
3. 风险与阻塞项回看：上期风险是否缓解

## 命名与索引

- 文件名：`RT-{序号}-{主题}.md`（序号从 001 全局递增，不随阶段重置）
- 模板：`docs/retrospectives/template.md`
- 本篇 README 底部维护索引表；每行末列「复盘时已归档数」登记该次复盘时任务卡归档总数，`patrol.ps1` 以此为基线（缺省 0）判断是否再次触发复盘（自上次复盘新增 ≥10 张时提示）
